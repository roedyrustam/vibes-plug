# Privacy Policy / Kebijakan Privasi

**vibes-plug** — Universal AI Agent Swarm & MCP Plugin  
Version 4.7.0 | Effective: 2026-11-01

---

## Data Collection / Pengumpulan Data

vibes-plug runs **entirely locally** on your machine. No telemetry, analytics, or personal data is transmitted to external servers by default.

**Data vibes-plug does NOT collect:**
- Personal identifiable information (PII)
- Code or file contents sent to external servers
- Usage analytics or crash reports (without explicit opt-in)
- API keys or secrets

## Telemetry (Opt-In Only)

The optional telemetry feature (`vibes telemetry --enable`) only records:
- Anonymized skill invocation counts (no content)
- Platform identifier (cursor, antigravity, claude-code)
- vibes-plug version

Telemetry can be disabled at any time: `vibes telemetry --disable`

## Third-Party Services

When using MCP tools that connect to external APIs (e.g., Supabase, GitHub), data handling is governed by those services' own privacy policies.
