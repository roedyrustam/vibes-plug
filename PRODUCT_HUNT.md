## 💬 Frequently Asked Questions (FAQ)

**Q: Do I need to pay for anything?**  
A: No! VibesPlug Pro is 100% free and open-source under the MIT license. You only use your own LLM API keys or IDE subscriptions (Cursor, Antigravity, Claude Code).

**Q: Does it slow down my IDE?**  
A: No. Unlike heavy local python agents, VibesPlug uses deterministic KV-cache prefixing, which actually speeds up LLM responses by up to 10x via prompt caching.

**Q: How do I install it in Cursor or Claude Code?**  
A: Run `npx vibes-plug --all` in your terminal. It automatically places `.cursorrules`, `CLAUDE.md`, and `AGENTS.md` into your project.
