## 🎯 1. Algoritma GitHub Trending: Cara Kerjanya

GitHub Trending tidak dihitung berdasarkan total akumulasi bintang historis, melainkan **Star Velocity (Kecepatan Bintang Baru per Satuan Waktu)**:
- **Daily Trending (Kategori JS/TS/AI):** Butuh ~40 - 80 stars baru dalam 12–24 jam.
- **Daily Trending (Overall / All Languages):** Butuh ~150 - 250 stars baru dalam 24 jam.
- **Weekly Trending (Overall):** Butuh ~300 - 600 stars dalam rentang 7 hari stabil.
- **Faktor Penguat:** 
  1. Rasio fork (10-20% dari star).
  2. Diversitas IP/akun pengguna unik (bukan bot).
  3. Traffic referral dari multi-sumber: Hacker News, Twitter/X, Reddit, LinkedIn, Discord.
  4. Aktivitas repo (komit berkala, issues, discussions aktif).

> **URL:** `https://news.ycombinator.com/submit`  
> **Tips:** Komunitas HN sangat kritis terhadap buzzword kosong. Gunakan bahasa teknis, jujur, jelaskan arsitektur dan trade-offs.

**Title:**
```text
Show HN: VibesPlug – A 161-skill multi-agent swarm architecture for IDEs
```

**Content:**
```text
Hey HN,

Over the past months of building full-stack systems with coding assistants (Cursor, Claude Code, Antigravity, Codex), we noticed a recurring failure mode: when asked to scaffold or maintain complex projects, single-prompt models blur abstractions, introduce subtle regression bugs, and accumulate dead code ("AI slop").

We built and open-sourced VibesPlug (MIT): https://github.com/roedyrustam/vibes-plug

Key architectural components:
1. Swarm Director Pattern: User prompts are intercepted, classified, and decomposed into cooperating subagent workflows rather than executed as a single monolithic generation.
2. 161 Domain-Specific Skills: Structured markdown contracts covering UI design tokens (Tailwind v4, modern CSS native), backend runtimes (Bun, Hono, Go, Rust), payment standards (DOKU SNAP BI, Stripe), and verification (TDD self-healing, in-memory DB sandboxing, Z3 theorem proving).
3. Sovereign Anti-Slop Directive: Automated AST-based static auditor (scripts/check-anti-slop.js) that enforces 0 placeholder comments, 0 fake mocks, and strictly typed contracts before code is accepted.
4. Model & IDE Portability: Automatically provisions config files for Antigravity, Claude Code (CLAUDE.md), Cursor (.cursorrules), Windsurf, Codex, and Trae.
5. Vibes Studio & Native MCP Server: Zero-dependency web cockpit and JSON-RPC 2.0 MCP server with 10 tools (AST symbol queries, SQL RLS validation, and KV-cache prefixing).

Try it in your terminal:
$ npx vibes-plug init

Repository: https://github.com/roedyrustam/vibes-plug

We would love feedback from the HN community on multi-agent decomposition patterns, token caching economics, and IDE ergonomics!
```

- **Autonomous Swarm Director**: You don't have to manually type `@skill-name`. The orchestrator inspects what you're doing and dynamically binds cooperating specialists (e.g. `senior-frontend` + `tailwind-expert` + `form-validation-expert`).

- **Vibes Studio**: Runs a zero-dependency local web cockpit (`vibes studio`) to explore all skills and inspect agent architecture.
