## 🎯 1. Algoritma GitHub Trending: Cara Kerjanya

GitHub Trending tidak dihitung berdasarkan total akumulasi bintang, melainkan **Star Velocity (Kecepatan Bintang Baru per Satuan Waktu)**:
- **Daily Trending (Kategori JS/TS/AI):** Butuh ~50 - 100 stars dalam 12–24 jam.
- **Daily Trending (Overall / All Languages):** Butuh ~150 - 250 stars dalam 24 jam.
- **Faktor Penguat:** Rasio fork, diversitas IP/akun pengguna unik, traffic referral dari Hacker News, Twitter/X, dan Reddit.

### What makes it different from normal rule files?
- **Swarm Director Engine**: You don't need to manually tag `@skill-name`. The orchestrator inspects your intent and dynamically binds cooperating specialists (e.g. `senior-frontend` + `tailwind-expert` + `form-validation-expert` for UI tasks).
- **9-Phase Zero-To-Prod**: Forces the agent to create PRD.md, ERD.md, and architecture maps BEFORE writing any code.
- **Phase 9 Zero-Tech-Debt Auditor**: Automatically cleans up dead code, stray logs, and magic numbers before shipping.
