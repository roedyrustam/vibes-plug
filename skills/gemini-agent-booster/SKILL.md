# Gemini Agent Booster & Multimodal Powerpack

[English](#english) | [Bahasa Indonesia](#bahasa-indonesia)

---

<a name="english"></a>
## English

### Description
This skill activates the full potential of Gemini models (Gemini 3.6 Flash / Pro) inside Antigravity IDE. It leverages Gemini's native ultra-large context window (1M+ tokens), multimodal vision, subagent orchestration, and artifact capabilities to perform complex full-stack engineering, rapid visual debugging, and deep architectural reasoning.

### Key Gemini Superpowers Activated

#### 1. 1M+ Long-Context Deep Synthesis
- **Whole-Codebase Reasoning**: Maps cross-file dependency graphs across dozens of modules simultaneously without truncation.
- **Root-Cause Log Diagnostics**: Reads full stack trace logs and environment configs in a single pass to pinpoint hidden bugs instantly.

#### 2. Multimodal Vision & Visual Verification
- **Visual UI Auditing**: Analyzes UI screenshots, mockups, and wireframes via Gemini Vision to ensure pixel-perfect fidelity.
- **Browser Subagent Loop**: Combines `browser_subagent` and vision analysis to visually inspect DOM elements, responsive layouts, and interactive state transitions.

#### 3. High-Speed Tooling & Parallel Execution
- **Background Task Efficiency**: Launches terminal builds/tests in background tasks (`run_command`) and reacts asynchronously to completion events.
- **Artifact-Driven Planning**: Generates interactive implementation plans, sequence diagrams, and architecture blueprints in markdown artifacts.

<a name="bahasa-indonesia"></a>
## Bahasa Indonesia

### Deskripsi
Skill ini mengaktifkan potensi penuh model Gemini (Gemini 3.6 Flash / Pro) di dalam Antigravity IDE. Skill ini memanfaatkan *ultra-large context window* bawaan Gemini (1M+ token), kemampuan penglihatan multimodal (*vision*), orkestrasi subagent, serta pembuatan *artifact* untuk melakukan engineering full-stack tingkat lanjut, debugging visual cepat, dan analisis arsitektur mendalam.

### Kemampuan Utama Gemini Yang Diaktifkan

#### 1. Sintesis Mendalam Long-Context 1M+ Token
- **Analisis Seluruh Codebase**: Memetakan grafik ketergantungan antar-file di puluhan modul secara bersamaan tanpa kehilangan konteks.
- **Diagnostik Log Tanpa Tebak-Tebakan**: Membaca *stack trace log* utuh dan konfigurasi lingkungan dalam satu putaran untuk menemukan akar masalah secara instan.

#### 2. Vision Multimodal & Verifikasi Visual
- **Audit UI Visual**: Menganalisis *screenshot* UI, *mockup*, dan desain via Gemini Vision untuk memastikan presisi tampilan tingkat piksel.
- **Siklus Browser Subagent**: Menggabungkan `browser_subagent` dan analisis visual untuk memeriksa elemen DOM, tata letak responsif, dan animasi antarmuka secara langsung.

#### 3. Eksekusi Paralel & Perkakas Kecepatan Tinggi
- **Efisiensi Background Task**: Menjalankan *build* dan *test* di latar belakang (`run_command`) dan merespons hasil secara asinkron tanpa *polling*.
- **Perencanaan Berbasis Artifact**: Menghasilkan rencana implementasi interaktif, diagram Mermaid, dan cetak biru arsitektur pada dokumen *artifact*.
