# Nama Skill (Misal: Kode Bersih)

## Deskripsi
Jelaskan secara singkat apa tujuan dari skill ini. 
Contoh: "Skill ini mengatur gaya penulisan kode saya agar selalu menggunakan bahasa Indonesia untuk penamaan variabel."

## Instruksi
- Tulis instruksi nomor 1 di sini... (Misal: "Selalu berikan komentar dalam bahasa Indonesia di setiap fungsi.")
- Tulis instruksi nomor 2 di sini... (Misal: "Gunakan camelCase untuk penamaan variabel Javascript.")
- Tulis instruksi nomor 3 di sini...

## Kondisi Pemicu
(Opsional) Kapan aturan ini harus dijalankan? 
Contoh: "Aktif setiap kali pengguna meminta untuk menulis atau me-review kode."
