```bash

cd vibes-plug
npm install

# Run installer across all detected platforms:
npm run install-all
# (or node scripts/install.js --all)
```

- `vibes compile-cache` — Kompiliert deterministische KV-Cache-Präfixe (>1024 Tokens) für 75–90% Kostensenkung.
- `vibes db:eval` — Simuliert und prüft SQL-DDL-Migrationen im Speicher auf RLS-Sicherheit.
- `vibes ast <action>` — Führt AST-Symbolabfragen durch und berechnet den Refactoring-Blast-Radius.
- `vibes arbitrate` — Bewertet konkurrierende Code-Entwürfe mittels Process Reward Models (PRM).
- `vibes verify-invariants` — Mathematischer Beweis von Zustandsübergängen & SMT-LIB 2.0 Generierung für Z3.
- `vibes swarm "<task>"` — Führt den autonomen Swarm Director aus (Fan-Out/Fan-In, Saga, Critic-Validator).
- `vibes memory` — Lokales episodisches Gedächtnis und ultrakompakte Checkpoints (<150 Tokens).
- `vibes mcp` — Startet den nativen Model Context Protocol (MCP v1.x) Server über stdio.
- `vibes anti-slop` — Erkennt und eliminiert unfertigen Code, `// TODO` und leere Stubs.

- `vibes init <project-name>` — 8フェーズ Zero-To-Prod 開発プロジェクトを初期化。
